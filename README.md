# QRコードバトラー

身のまわりの**QRコードからモンスターが生まれる**ブラウザゲームです。ドリルの自動発掘でポイントを集め、QRコードを読んで召喚し、トランプ風のカードバトルで戦います。

- 遊ぶ: https://anit0328.github.io/qr-battler/
- バージョン: Ver0.4

## 遊び方

| 画面 | できること |
| --- | --- |
| **発掘** | ドリルが自動で掘りすすむ。ふつうのブロックで**コイン**（ドリル強化用）、QRブロックで**QRポイント**（召喚・BET・Lvアップ用）が集まる。閉じている間も半分のペースで掘る（最大48時間） |
| **召喚** | カメラか画像でQRコードを読むとモンスターが生まれる。同じQRからはいつも同じモンスター。読めるのは http〜 のお店やサイトのQRコードだけで、同じドメインからは1回だけ召喚できる |
| **牧場** | パーティ（3体）を決める。お気に入り、QRポイントでのLvアップ、1日1回むりょうの「きょうのおきゃくさん」 |
| **バトル** | 自動マッチングのカードバトル。勝つと相手のモンスターを1体コピーできる |

### バトルのルール

- 手札は5枚（**キング**か**ジョーカー**が1枚＋**ナイト**が4枚）。おたがいの手札は見えている
- キング ＞ ナイト ＞ ジョーカー ＞ キング。ジョーカーでキングをたおすとダメージ3倍
- ナイトどうしは数字勝負（2が最弱、Aが最強）。キングどうしは相打ち
- 5枚で1セット、全4セット。セットのはじめに **BET**（勝てば3倍）か **シャッフル**（5枚引き直し）を選ぶ
- モンスターがたおれたら、おたがい5枚から仕切り直し
- カードはふだんオートで出る。時間内にタップすれば自分で選べる

## 動かし方

ビルドは不要です。`index.html` 1ファイルだけで動きます。

```bash
npx serve .
# または
python3 -m http.server 8000
```

カメラを使うには **HTTPS**（または localhost）で開く必要があります。

### オンライン対戦について

オンライン対戦は、WebSocket（MessagePack）で通信するマルチプレイ用サーバーにつないで動きます。

- 接続先は `index.html` の中に書かれていて、`?mp=wss://...` で上書きできる
- 対戦相手が見つからないときやオフライン設定のときは、CPUと対戦する
- 対戦は「シード付き乱数のロックステップ同期」と「出すカードのコミット・リビール」で、不正ができないようにしている

## デバッグ用パラメータ

| パラメータ | 内容 |
| --- | --- |
| `?dbg=1` | `window.__qb` を公開し、文字入力での召喚ボタンを表示する |
| `?mplog=1` | 画面上に通信ログを表示する |
| `?mp=wss://...` | マルチプレイ用サーバーの接続先を変える |

## 技術メモ

- HTML / CSS / JavaScript の1ファイル構成（フォントは Google Fonts から読み込む）
- QRコードの読み取りには BarcodeDetector を使い、ない場合は jsQR（CDN）を使う
- QRコードの生成は自前のエンコーダを内蔵している（外部サービスは使わない）
- モンスターの見た目と能力は、QRの中身のハッシュから決まる（同じQRなら同じモンスター）
- 画像はCanvasで描画し、効果音・BGMはWeb Audio APIで生成している
- セーブデータはブラウザの localStorage に保存する
